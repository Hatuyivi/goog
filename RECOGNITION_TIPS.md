# Советы по улучшению распознавания помещений

## Что изменено

### 1. Трёхуровневая пороговая обработка
- **Strict** (строгий) — основная структура стен
- **Loose** (свободный) — полупрозрачные границы, тонкие стены
- **Very Loose** (очень свободный) — очень светлые стены, пунктирные линии

### 2. Адаптивный fillRatio
- Маленькие помещения (< 1% площади): fillRatio снижен до 0.15
- Средние помещения (< 5% площади): fillRatio 0.18
- Большие помещения: стандартный fillRatio

### 3. Помещения у границ
- Теперь разрешены помещения, касающиеся краёв плана
- Отбрасываются только очень большие области (> 40% изображения)

### 4. Снижена минимальная площадь
- С 0.2% до 0.15% от площади изображения
- Позволяет находить маленькие помещения (санузлы, кладовки)

## Параметры для настройки

### Чувствительность стен
- **0 (авто)** — автоматический порог Otsu (рекомендуется)
- **80-120** — для светлых планов
- **140-180** — для тёмных планов
- **200-240** — для очень контрастных планов

### Сглаживание полигонов
- **1-2 px** — максимальная детализация (много вершин)
- **3-4 px** — баланс (рекомендуется)
- **5-8 px** — упрощённые формы
- **10+ px** — очень грубые прямоугольники

## Если помещения не распознаются

1. **Откройте консоль браузера** (F12 → Console)
2. Посмотрите логи `[wallSens]`:
   - `near-miss rejects` — помещения, которые почти прошли фильтры
   - `reason` — причина отбрасывания (tooSmall, fillRatio, border)

3. **Настройте параметры**:
   - Если `tooSmall` — уменьшите минимальную площадь (пока нет в UI)
   - Если `fillRatio` — помещение имеет сложную форму (алгоритм уже адаптивный)
   - Если `border` — помещение касается края (теперь разрешено)

4. **Используйте режим редактирования**:
   - Нажмите "Редактировать" после распознавания
   - Добавьте пропущенные помещения вручную (режим "Рисовать")
   - Система запомнит ваши правки для обучения

## Режим обучения

Планировщик запоминает ваши правки:
- Какие помещения вы удалили (ложные срабатывания)
- Какие помещения вы добавили вручную
- Какие размеры помещений типичны для ваших планов

При повторном анализе похожих планов алгоритм автоматически применит накопленные знания.

## Технические детали

### Алгоритм распознавания:
1. Преобразование в оттенки серого
2. Три прохода бинаризации (Otsu, Otsu-30, Otsu-50)
3. Эрозия для утолщения стен
4. Поиск связных компонент (flood fill)
5. Фильтрация по площади и форме (адаптивная)
6. Слияние кандидатов с разных проходов (IoU < 0.3-0.4)
7. Трассировка контуров
8. Упрощение полигонов (RDP)
9. Постобработка (удаление дубликатов, вложенных помещений)

### Диагностика в консоли:
```
[wallSens] threshold: { T_otsu, T_global, T_loose, T_veryLoose }
[wallSens] floodFill regions: { strict, loose, veryLoose }

[wallSens] merge: { fromStrict, looseAdded, veryLooseAdded, total }
[wallSens] polygons: { built, polyTooShort, simpTooShort }
```
